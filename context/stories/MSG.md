## MSG · Messages

### MSG-01 Message about a gig (M4)
- AC1 Once someone applies or is invited, the business and creative can message each other in a thread tied to that application. `db` `e2e`
- AC2 When the project starts, the thread carries over into the project. `db`
- AC3 Messages arrive in real time and show sent and read states. `e2e`
- AC4 Only thread participants can read or send messages. `db`
- AC5 There are no cold DMs in Beta 1: a thread needs an application or invite (Q4).

### MSG-02 Inbox (M4)
- AC1 The inbox lists threads by latest message, with unread counts and a badge on the nav icon. `e2e`
